    이력서 상세

    Drive 설정/동기화

    Google Drive 부서 설정(dept_config.json)과 DB/폴더 매핑 상태를 동기화합니다. (폴더 구조만 동기화하며 이력서 파일은 이동·삭제하지 않습니다.)

    부서 설정 JSON 관리

    Google Drive의 config/dept_config.json 파일을 부서 데이터 원천으로 사용합니다. DBeaver export JSON 파일을 업로드하면 서버가 자동으로 정규화하고, 정규화된 내용을 화면에서 확인/수정한 뒤 Drive에 저장할 수 있습니다.

    부서 DB 동기화 (resume_ai)

    부서 원천: Google Drive config/dept_config.json · 부서 조회 기준: PostgreSQL resume_ai.departments · Drive 폴더 매핑 기준: PostgreSQL resume_ai.dept_drive_folders

    수동 동기화

    DB(resume_ai.departments) 의 부서를 기준으로 inbox / completed / failed 하위에 부서별 폴더를 생성/재사용하고, 결과를 resume_ai.dept_drive_folders 에 저장합니다. (먼저 위에서 'Drive config → DB 부서 동기화'를 실행하세요. 여러 번 실행해도 안전합니다.)
